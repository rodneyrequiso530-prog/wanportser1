01 — About

About Me

I'm a student learning web development, and I enjoy seeing how design and code come together to make a page that people can actually use. I got curious about this field because every website I visit was built by someone, and I wanted to learn how to build my own. Right now I'm practicing through class activities and small projects, and I'm improving a little with each one.

I'm interested in clean, easy-to-use website design and in making pages that work well on both phones and computers. Right now I can build simple pages with HTML and CSS and I'm still learning JavaScript, so I'm not an expert yet. Next, I want to build more complete projects, get better at fixing my own mistakes, and learn how to publish and update a site on my own.
